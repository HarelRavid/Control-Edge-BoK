# Control Edge - מאגר הידע לסדרת הפודקאסט

המאגר מרכז את כל החומר שנבנה לסדרת הפודקאסט על בקרת מכונות ומערכות תעשייתיות.

## עקרון העבודה

- קובצי `full.he.md` ו-`full.en.md` יחד עם `script.he.txt` ו-`script.en.txt` הם מקורות העבודה של כל פרק.
- קובצי `full.*.txt` הם גרסאות טקסט פשוט להעלאה למודלים.
- קובצי `script.*.txt` מכילים את הדיאלוג הקנוני להפקת האודיו.
- קובצי `notebooklm_prompt.*.txt` מכילים הנחיה מוכנה להפקת אודיו.
- קובצי PDF ו-DOCX נשמרים בתיקיית `archive` כאשר הם זמינים, ואינם המקור המועדף ל-Review.

## סטטוס

פרקים 1-11 הושלמו בעברית ובאנגלית. הפרק הבא המתוכנן הוא פרק 12: Industrial Cybersecurity - סייבר למערכות בקרה תעשייתיות.

לסקירה מלאה עם Claude יש להשתמש ב-`prompts/CLAUDE_REVIEW_PROMPT.txt` ובקובצי `exports`.
