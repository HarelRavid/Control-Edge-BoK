# Control Edge - מאגר הידע לסדרת הפודקאסט

המאגר מרכז את כל החומר שנבנה לסדרת הפודקאסט על בקרת מכונות ומערכות תעשייתיות.

## עקרון העבודה

- קובצי `full.he.md` ו-`full.en.md` הם מסמכי המקור הניתנים לעריכה.
- קובצי `full.*.txt` הם גרסאות טקסט פשוט להעלאה למודלים.
- קובצי `script.*.txt` מכילים את הדיאלוג בלבד.
- קובצי `notebooklm_prompt.*.txt` מכילים הנחיה מוכנה להפקת אודיו.
- קובצי PDF ו-DOCX נשמרים בתיקיית `archive` ואינם המקור המועדף ל-Review.

## סטטוס

פרקים 1-9 הושלמו בעברית ובאנגלית. הפרק הבא המתוכנן הוא פרק 10: בקרת תהליך ו-PID.

לסקירה מלאה עם Claude יש להשתמש ב-`prompts/CLAUDE_REVIEW_PROMPT.txt` ובקובצי `exports`.
